# Security Policy

If you believe you've found a security vulnerability, **please do not open a public issue**. Email **<boris@mrakbook.com>** with details and a proof‑of‑concept if possible.

## Supported versions
This project is pre‑1.0; only the latest commit on `main` receives security fixes.

## What to include in your report
- Affected component and configuration (OS, Python, DB, llama.cpp version)
- Steps to reproduce
- Potential impact and suggested remediation (if any)

We will acknowledge your report and coordinate a fix and disclosure timeline.
